# Project Design Registry — Grace Notes entry (12 Nov 2026)

## The three most recent fleet projects (inspected live 12 Nov 2026)

### NyayaSeal — https://nyayaseal.vercel.app
- Concept: legal-document authenticity; "the hash is the address".
- Palette: dark navy/ink with bright accents; dense, technical.
- Typography: sans, technical; numbered workflow sections 01–05.
- Layout: long single page, upload/verify/vault/audit sections, data tables.
- Hero: headline + stats ("documents sealed / verifications / audit chain").
- Signature interaction: hash-and-verify workflow, tamper demo.
- 3D: draggable 3D stack of sealed-document cards.
- Motion: functional, restrained.

### YojanaSetu — https://yojanasetu-self.vercel.app
- Concept: officer dashboard for beneficiary data governance.
- Palette: government-dashboard neutrals, data-viz colours.
- Typography: sans, dashboard-dense.
- Layout: dashboard sections (totals, district map, enrolments, duplicates,
  eligibility trace, scheme registry).
- Hero: "Officer Dashboard" with totals.
- Signature interaction: clickable district blocks filter the whole dashboard.
- 3D: isometric district map — block height = enrolment volume, drag to rotate.
- Motion: functional rotation, keyboard-navigable.

### CageCheck — https://cagecheck.vercel.app
- Concept: "check the agent's code in a cage" — sandboxed code review.
- Palette: dark terminal/cage, monospace-adjacent feel.
- Typography: sans/mono, terse.
- Layout: minimal single-purpose tool page (paste snippet → check → receipt).
- Hero: one-line value prop + cage rules list.
- Signature interaction: paste-and-check with policy receipts.
- 3D: (cage motif; containment framing rather than a scene).
- Motion: minimal, tool-like.

## Grace Notes — how it is recognisably different
- Concept: chapel/parchment, not legal, government or terminal. A quiet
  devotional companion, not a workflow tool.
- Palette: warm parchment `#f7f1e3`, ink, candle-gold, ruby — light, not dark.
  No navy, no teal, no terminal black.
- Typography: serif-led editorial (Palatino/Georgia) for headlines and all
  Scripture; sans only for chrome. The fleet projects are sans-led.
- Layout: editorial single page with chapter numerals (01–04) and a
  two-column hero; no dashboard, no tables, no upload workflow.
- Hero: a stained-glass window beside a serif headline — an object, not a
  stats row or a form.
- Signature interaction: ask-and-be-answered with citations, plus a
  *designed refusal* ("not found in the provided passages") as a first-class
  state — none of the fleet projects has a refusal state.
- 3D: CSS-3D stained-glass window (panes at translateZ depth, pointer tilt)
  where colour encodes topic and each pane is a filter. Different object,
  different purpose, different technique from the document stack and the
  district map.
- Motion: kinetic type + mask reveal + magnetic chips — editorial motion,
  not dashboard rotation.

**Verdict: PASS — distinct in concept, palette, typography, layout, hero,
signature interaction and 3D treatment, not merely a new accent colour.**
